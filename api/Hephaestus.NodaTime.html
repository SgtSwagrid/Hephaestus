Namespace Hephaestus.NodaTime

Classes

DayPeriodProjection

Periods measured in whole days. Only periods made of days and weeks have a fixed length, so only those can be encoded: a month is not a number of days.

DurationProjection

Durations measured in multiples of a unit.

InstantProjection

Instants measured in multiples of a unit since an origin.

LocalDateProjection

Dates measured in whole days since an origin.

LocalDateTimeProjection

Local date-times measured in multiples of a unit since an origin, along a local time line on which every day has twenty-four hours (as it has for a railway timetable within one zone).

LocalTimeProjection

Times of day measured in multiples of a unit since midnight. A time of day cannot leave its day, so constrain such variables to it (time.Between(LocalTime.Midnight, LocalTime.MaxValue)); numbers outside the day decode to its nearest end.

NodaTimeOperators

A plain NodaTime value shifted by a quantity is a point whose origin is that value: start + dwell, dwell + start, start - dwell.

NodaTimeVariables

Typed variables for the NodaTime types, offered alongside Variable.Continuous and friends. In every case unit is what the number one stands for (a second unless stated), and inWholeUnits makes the underlying variable an integer, for quantised times.

OffsetDateTimeProjection

Offset date-times measured along the global time line; decoded values carry the origin's offset.

ZonedDateTimeProjection

Zoned date-times measured along the global time line; decoded values are in the origin's zone.
