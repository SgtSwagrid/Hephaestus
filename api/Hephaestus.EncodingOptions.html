Parameters

StrictnessEpsilon double

The gap that stands in for strictness over the reals: a < b is encoded as a + epsilon <= b. It should comfortably exceed the solver's feasibility tolerance. Whole-valued comparisons use a gap of exactly one and are unaffected.

FallbackBigM double?

The big-M to use when none can be derived because an expression is unbounded. Leave it unset (the default) to get an error naming the unbounded variables instead: a guessed big-M that is too small silently cuts off solutions, and one that is too large invites numerical trouble.

BoundPropagationRounds int

The most sweeps of bound propagation to run over the unconditional constraints. The first sweep reads off stated bounds such as x <= 10; later ones derive implied bounds.

AuxiliaryPrefix string

The prefix for the names of auxiliary binary variables.
